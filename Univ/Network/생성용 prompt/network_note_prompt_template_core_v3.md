# 작성 규칙

1. 긴 서술형 문단을 피해주세요.
   - 한 문단 3줄 이상 금지
   - 설명은 짧은 bullet로 작성
   - 가능하면 `개념 = 의미` 형태 사용

2. 섹션을 과도하게 쪼개지 말아주세요.
   - `손필기식 표현`, `보강 설명`, `시험 포인트`를 매번 따로 만들지 말 것
   - 대신 각 개념 아래에 짧은 고정 항목만 사용

3. 각 큰 개념은 아래 형식으로 정리해주세요.

## N. [개념명] (p** ~ p**)

- 핵심: ...
- 구조: A → B → C
- 암기: ...
- 주의: ...

필요할 때만 표/도식을 추가해주세요.

4. 손필기 표현은 본문에 자연스럽게 섞어주세요.
   - 예: `Global = 전체 지도를 들고 계산`
   - 예: `DV = 이웃이 알려준 거리표로 계산`
   - 단, 별도 보강 섹션으로 빼지 말 것

5. 교안과 교차 확인이 가능해야 합니다.
   - 큰 제목 옆에 페이지 범위 표시
   - 정확하지 않으면 `대략 p** 부근`으로 표시

6. 중요한 개념은 임의로 생략하지 말아주세요.
   - 교안 핵심 개념
   - 손필기 메모에 적힌 개념
   - 비교형/서술형 시험에 나올 개념
   - 수식/프로토콜/알고리즘 흐름

7. 그림은 필기 가능한 형태로 바꿔주세요.
   - 복잡한 그림 전체 복붙 X
   - 핵심 구조만 ASCII 도식으로 단순화

예시:

```text
[Client] → [Router] → [Server]
 요청        전달        응답
```

8. 수식은 아래처럼 정리해주세요.

```text
수식: ...
의미: ...
암기: ...
```

9. 마지막에는 반드시 비교표를 넣어주세요.
   - 헷갈리는 개념끼리 비교
   - 시험 직전 확인용

10. 마지막에는 체크리스트를 넣어주세요.
    - 설명할 수 있는가?
    - 표를 읽을 수 있는가?
    - 알고리즘 흐름을 말할 수 있는가?

## 2. 빠르게 쓰는 짧은 버전

```md
[챕터명] 교안 PDF와 손필기 메모를 바탕으로
핵심만 바로 필기 가능한 전사 노트를 만들어주세요.

작성 방식:

- 긴 서술문 금지

## 3. Chapter 5용 요청 예시

```md
Chapter 5 Network Layer: Control Plane 교안 PDF와 손필기 메모를 바탕으로
핵심만 바로 필기 가능한 전사 노트를 만들어주세요.

참고 자료:

- Chapter_5_v80_260512_092901.pdf
- 20260505_NL_ControlPlane1.txt
- 20260505_NL_ControlPlane2.txt
- 20260505_NL_ControlPlane3.txt

작성 방식:

- 긴 서술문 금지
- 항목형 bullet, 화살표, 비교표 중심
- 각 개념 제목 옆에 페이지 범위 표시
- 손필기 표현은 본문에 통합
- 불필요한 `손필기식 표현 보강`, `보강 설명` 섹션 생성 금지
- 교안과 대조하면서 바로 옮겨 적을 수 있는 밀도로 작성

반드시 포함할 개념:

- data plane vs control plane
- forwarding vs routing
- per-router control plane vs SDN control plane
- routing protocol goal, path, cost
- graph abstraction, G=(N,E), link cost
- global/link-state vs decentralized/distance-vector
- Dijkstra algorithm, D(v), p(v), N'
- oscillation
- Bellman-Ford equation
- Distance Vector 특징
- good news travels fast / bad news travels slow
- count-to-infinity, routing loop, black-holing
- AS, intra-AS, inter-AS, gateway router
- OSPF, hierarchical OSPF
- BGP, eBGP, iBGP
- prefix, AS-PATH, NEXT-HOP, policy-based routing
- BGP messages: OPEN, UPDATE, KEEPALIVE, NOTIFICATION
- hot potato routing
- SDN 구조, OpenFlow, controller
- northbound API, southbound API
- ICMP, ping, traceroute
- network management
- SNMP, MIB
- NETCONF, RPC, XML, YANG

출력:

- `.md` 파일
- `.txt` 파일
- 파일명: `chapter5_control_plane_core_handnote.md`
```
